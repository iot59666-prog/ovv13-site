# Сайт «Шашлык ovv13»

Одностраничный сайт сети ovv13 в Кокшетау: ресторан на Ауельбекова 62а и столовые на Центральном рынке и на Абая 122.
Сайт статичный (HTML/CSS/JS), сервер не нужен. Чтобы посмотреть, откройте `index.html` двойным кликом.

## Что умеет
- Языки RU и KZ, выбранный язык запоминается.
- Витрина «Хиты» с вращающимися тарелками и полное меню с вкладками и поиском.
- При наведении карточка блюда увеличивается и показывает описание, состав и цену. На телефоне по нажатию открывается нижняя панель.
- Корзина: заказ уходит готовым сообщением в WhatsApp +7 775 307 07 17 (доставка или самовывоз, выбор точки).
- Бронь стола и банкета тоже уходит в WhatsApp.
- Отзывы и рейтинги с 2GIS, галерея, три точки с режимом работы (статус «Открыто/Закрыто» по времени Кокшетау) и тёмная карта.
- Анимации: прелоадер, побуквенное появление заголовков, курсор с подсветкой, искры над мангалом, плавная прокрутка.
  Если у посетителя в системе включено «уменьшить движение», анимации отключаются.

## Структура
```
index.html          разметка
css/style.css       стили (цвета — переменные в начале файла)
js/menu-data.js     МЕНЮ, хиты, точки сети  ← правится чаще всего
js/i18n.js          все тексты RU / KZ
js/app.js           логика и анимации
img/plates/         круглые «тарелки» (временные, стоковые)
img/menu/           сюда класть свои фото блюд
img/gallery/        галерея
```

## Как поменять цену или блюдо
Откройте `js/menu-data.js`, найдите блюдо и поменяйте `price: 2800`. Новое блюдо добавляется копированием любого блока `{ id: ..., }`.

## Как поставить свои фото блюд
1. Сфотографируйте блюдо **строго сверху**, тарелка по центру кадра, квадрат.
2. Обрежьте по кругу с прозрачным фоном (подойдёт любой онлайн-сервис удаления фона) и сохраните как `img/menu/<id>.webp` или `.png`, примерно 800×800.
3. В `menu-data.js` добавьте блюду поле `photo: "img/menu/<id>.webp"`.

## Как выложить в интернет (бесплатно)
**Netlify (проще всего):** зайдите на app.netlify.com/drop и перетащите папку `ovv13-site`. Через минуту появится ссылка; там же можно привязать свой домен (например, ovv13.kz).

**GitHub Pages:** создайте репозиторий, загрузите файлы, затем Settings → Pages → Deploy from branch → `main`.

Библиотеки (GSAP, Lenis, Leaflet) и шрифты грузятся с CDN. Если CDN недоступен, сайт работает без анимаций и карты.
